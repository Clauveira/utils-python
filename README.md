# utils-python
Este repositório oferece um conjunto de scripts utilitários em Python projetados para simplificar tarefas rotineiras de processamento de imagens. As funcionalidades incluem conversão para Base64, remoção de fundo, geração de máscaras binárias e criação de arquivos auxiliares. Desenvolvidas para uso pessoal, estas ferramentas visam otimizar e acelerar processos específicos, especialmente na fase de preparação de datasets para treinamento de modelos de inteligência artificial.

Instale as bibliotecas necessárias com:

```bash
pip install rembg opencv-python pillow numpy onnxruntime-gpu
```
